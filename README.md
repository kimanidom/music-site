
MelodyMart – Musical Instrument Store
A web-based store to showcase and manage musical instruments | Version: April 30, 2025
By  Dominic Kimani
📖 Description
MelodyMart is a front-end web application designed to showcase musical instruments in a virtual store setting. The website allows users to:

Browse a list of musical instruments with images and names.

Add new instruments through a dedicated form page.

Submit contact information using a validated contact form.

View dynamic content powered by JavaScript, including personalized greetings and locally stored product data.

This app is built entirely with HTML, CSS, and JavaScript and uses localStorage to persist data across pages without a backend.

🛠️ Setup/Installation Requirements
To run the application:

Clone or download the project folder to your computer.

Open the folder using a code editor like VS Code.

Use Live Server extension (or any static server) to open index.html.

Make sure all files are in the same directory structure:

🐞 Known Bugs
Product images must be valid URLs when adding a new item, or they won’t display.

No support for editing or deleting existing products.

Some image URLs may fail if the link is broken or external hosting is down.

Planned fixes include implementing in-browser image previews and product editing.
